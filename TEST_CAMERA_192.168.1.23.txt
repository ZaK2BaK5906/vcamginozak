🚨 PROBLÈMES COURANTS :

❌ "Connection refused"
   → Vérifiez que la caméra est allumée et sur le réseau
   → Vérifiez l'IP avec AXIS IP Utility

❌ "Authentication failed"
   → Le mot de passe contient ! qui doit être encodé en %21
   → Vérifiez que le compte root est activé

❌ "Stream not found"
   → Essayez les autres URLs ci-dessus
   → Vérifiez dans l'interface web quelle URL utiliser

❌ "Timeout"
   → Vérifiez le firewall de votre PC
   → Vérifiez que vous êtes sur le même réseau
